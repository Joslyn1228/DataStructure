# 双索引批次表前端演示页

这是一个纯前端单页演示，主要用于答辩时展示：

- 批次主表 `batches`
- 名称索引表 `name_index`
- 预警时间索引堆 `warning_heap`
- 操作栈 `operation_stack`
- 任务队列 `task_queue`

## 打开方式

直接双击 [index.html](./index.html) 即可。

## 演示建议

1. 先点“初始化”，说明五种结构全部置空。
2. 再点“批次入库”和“双索引”，解释主表与索引的关系。
3. 点“名称查询”展示 `name_index` 的作用。
4. 点“临期预警”和“出库调度”展示 `warning_heap` 的价值。
5. 点“任务队列”和“撤销恢复”展示 `task_queue`、`operation_stack` 的区别。

## 数据说明

页面中的样例批次来自你们已经整理好的真实粮食交易清单数据，字段口径与作业文档保持一致。
